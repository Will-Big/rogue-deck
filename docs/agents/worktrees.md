# 워크트리와 메인 체크아웃

**언제 읽나:** 브랜치를 파거나 메인 체크아웃에 커밋하려 할 때. AGENTS.md 규칙 15·16·18·19가 이
문서를 가리키며, 규칙에는 명령만 남기고 근거는 여기 있다.

`## 규칙 N —` 절은 훅이 통째로 잘라 stderr로 내보낸다(`Tools/rule-note.sh`). 그러니 그 절은
**위반한 사람이 그 자리에서 읽고 납득할 분량**으로 유지한다 — 200토큰 안쪽이다.

## 규칙 15 — 메인 체크아웃의 브랜치를 전환하지 않는다

**이유는 병렬 작업이 아니라 열려 있는 에디터다.** 메인 체크아웃(`/Users/ish/Git/rogue-deck`)에는
사용자의 Unity 에디터가 떠 있고, 브랜치를 전환하면 그 에디터가 변경을 그대로 먹는다. 대량
리임포트가 돌고 참조가 깨진다.

2026-09-04 관찰: `manifest.json` **한 줄** 변경만으로도 떠 있던 에디터가 패키지 임포트를 시작했다.
브랜치 전환은 그보다 수천 배 크다.

**그러므로 세션이 하나뿐이고 병렬 작업이 전혀 없는 날에도 이 규칙은 유효하다.** "지금은 나
혼자니까 괜찮다"는 우회 사유가 되지 않는다. 실측상 브랜치 작업이 master 작업과 실제로 겹친 것은
최근 머지 20건 중 3~4건뿐이며, 규칙을 지탱하는 것은 그쪽이 아니다.

코드 작업은 전용 워크트리에서 한다. 세션 도구가 만드는 워크트리(`.claude/worktrees/<작업명>`)를
그대로 쓰고, 도구 없이 직접 만들 때만 `git worktree add`를 쓴다. 브랜치 이름은 영어로 짓는다.

## 규칙 16 — 메인 체크아웃에서는 에디터가 보는 경로를 건드리지 않는다

메인 체크아웃에 직접 커밋해도 되는지는 **파일 종류가 아니라 경로**로 갈린다. 판정 기준은
"떠 있는 에디터가 그 경로를 임포트하느냐"다 — 규칙 15가 막으려는 위험과 정확히 같다.

```
Assets/  Packages/  ProjectSettings/   → 차단. 워크트리에서 한다
그 밖의 모든 것                        → 허용
```

문서(`.md`·`.html`), `docs/agents/`, `Tools/`, `.githooks/`, `.github/`, `.claude/`, `.gitignore`,
독립 이미지·오디오는 전부 허용이다. 머지는 `pre-commit`이 아니라 `pre-merge-commit`을 부르므로
워크트리 코드를 메인에서 합치는 평소 흐름은 영향받지 않는다.

**허용 목록이 아니라 차단 목록인 이유.** 2026-09-08 실측으로 최근 비머지 커밋 60개에 두 판정을
돌렸다. 확장자 허용 목록은 44건을 막았고 그중 **16건이 오탐**이었다 — 규칙 28이 요구하는 `.html`
설계 문서까지 막혀 규칙끼리 충돌했다. 경로 차단 목록은 29건을 막았고 **오탐 0**이며, 막힌 29건은
전부 `Assets/` 또는 `Packages/`를 건드렸다.

커밋 전 `git status`를 확인하고 요청받은 경로만 스테이징한다.

## 규칙 18 — 세션을 마칠 때 워킹 트리를 깨끗이 남긴다

커밋하거나, 못 하면 stash + 사유 기록. 시드 산출물·씬 파일 같은 생성물을 커밋되지 않은 채
방치하지 않는다.

**stash는 저장소 전체가 공유한다.** 다른 워크트리의 세션이 동시에 push·pop 할 수 있으므로 맨
`git stash` / `git stash pop`을 쓰지 않는다. 임시 WIP 커밋이 안전하고, 굳이 stash 해야 하면
`git stash push -u -m "<고유 태그>"`로 넣고 `git stash apply <sha>`로 꺼낸다.

## 규칙 19 — master 머지는 사용자 승인 후에만 한다

머지 전 `Tools/verify.sh` 전체 통과를 확인한다. CI가 push·PR마다 같은 명령을 돌리지만 그것은
마지막 그물이지 검증을 대신하는 것이 아니다.

## 워크트리 비용과 정리

| | 크기 |
|---|---|
| Unity를 돌리지 않은 워크트리 | 약 51MB |
| Unity 에디터·배치를 돌린 워크트리 | `Library/`로 **2.4GB** |

최근 100커밋 중 씬·프리팹을 건드린 것은 3건이라 대부분의 세션은 51MB짜리다. 다만 **한 번이라도
Unity를 돌린 워크트리는 머지 후 반드시 제거한다** — 쌓이면 그것만 수십 GB가 된다.

머지가 끝난 작업 브랜치와 워크트리는 함께 정리한다.
