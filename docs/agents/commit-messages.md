# 커밋 메시지

**언제 읽나:** 커밋 제목을 쓸 때, 또는 `commit-msg` 훅에 막혔을 때. AGENTS.md 규칙 27이 이
문서를 가리킨다.

## 규칙 27 — 커밋 메시지 제목과 본문은 한국어로 쓴다

형식은 `타입(범위): 한국어 제목`이다. 타입과 범위만 Conventional Commits 규약대로 영어를
유지하고, **콜론 뒤부터는 한국어로 고정한다.** 제목은 **현재형 평서문**으로 쓴다 — 종결어미
`-ㄴ다`로 끝난다(`만든다` · `높인다` · `뒤집는다` · `한다`).

```
쓴다:     refactor: 카드 SO를 제거하고 카드 원본을 JSON 하나로 만든다
쓴다:     fix(ui): 실행순서 배지의 가독성을 높인다
쓰지 않는다: docs: record card frame merge handoff
쓰지 않는다: fix(ui): improve execution order badge visibility
```

타입은 `feat` · `fix` · `docs` · `refactor` · `test` · `chore`.
범위는 `(ui)` · `(core)` · `(tools)`처럼 소문자 영어 한 낱말이며 생략할 수 있다.

영어 제목은 과거 커밋에 섞여 들어간 것이며 새 커밋에는 쓰지 않는다. **이미 푸시된 히스토리는
재작성해 고치지 않는다.** 브랜치 이름(규칙 15)은 이 규칙과 무관하게 영어를 쓴다.

## 훅이 검사하는 것

`.githooks/commit-msg`가 제목 한 줄을 본다.

```
^(feat|fix|docs|refactor|test|chore)(\([a-z]+\))?: .*[가-힣].*다\.?$
```

**끝을 `다`로 본다.** 「한다」라는 글자를 그대로 요구하면 `만든다`·`뒤집는다`·`붙인다`가 막힌다 —
2026-09-09 실측으로 최근 비머지 커밋 60건 중 **23건(38%)** 이 걸렸고, 위 "쓴다" 예시 두 줄도
그중에 있었다. `[가-힣]`이 남아 영어 제목은 여전히 막힌다.

머지 커밋과 리버트 커밋은 통과시킨다 — 메시지를 git이 만들기 때문이다.
`--no-verify`로 건너뛸 수 있지만 그렇게 만든 제목은 아무도 고쳐 주지 않는다.

## 본문

본문도 한국어로 쓴다. 무엇을 바꿨는지가 아니라 **왜 바꿨는지**를 적는다 — 무엇은 diff가 이미
말한다. 실측 수치가 있으면 넣는다. 이 저장소의 규칙 대부분이 커밋 본문에 남은 실측에서 나왔다.
