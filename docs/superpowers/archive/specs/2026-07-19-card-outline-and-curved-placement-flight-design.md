# 카드 선택 외곽선 및 곡선 배치 비행 설계

> **보관 문서:** 완료되었거나 현재 기준에서 대체된 역사 기록입니다. 현행 규칙의 권위 문서가 아니며, 현재 문서는 [`docs/superpowers/README.md`](../../README.md)에서 확인합니다.

## 1. 목적

기존 카드 선택 표현과 실행 카드 배치 모션을 다음과 같이 다듬는다.

- 손패에서 선택한 전체 크기 카드는 내부가 푸르게 채워지지 않고 프레임 외곽선만 푸르게 표시한다.
- 실행 카드가 손패에서 상단 레일 실루엣으로 이동할 때 숫자 `3`의 윗고리와 같은 곡선을 그린다.
- 카드의 윗변은 곡선 접선을 따라 `12시 → 2시 → 10시 → 9시` 방향으로 회전한다.
- `9시` 이후에는 실루엣 아래로 다시 꺾이지 않고 `9시 → 12시`로 풀리며 정방향으로 안착한다.

이 문서는
`2026-07-19-card-selection-placement-motion-design.md`의 선택 표현과 비행 경로를 보완하는 델타 설계다.
카드 배치 규칙, 비용, 자동 삽입 위치 및 두 단계 실루엣 확정 흐름은 변경하지 않는다.

## 2. 범위

### 포함

- 전체 크기 `CardView` 선택 효과를 중앙 채움 `Image`에서 `UnityEngine.UI.Outline`으로 교체
- 선택 없음, 황금색 Primary, 푸른색 Secondary 상태 유지
- 카드 프레임 원본 색과 내부 아트·본문 색을 바꾸지 않는 선택 표현
- 두 구간 Bézier 배치 경로와 곡선 접선 기반 Z축 회전
- `9시 → 12시` 최종 접근 구간의 실루엣 하단 경계 제한
- 기존 이동 중 축소, 입력 차단, 완료 콜백 및 임시 카드 정리 유지
- Unity EditMode 회귀 테스트와 수동 플레이 체크리스트 갱신

### 제외

- `RailCardView`의 배치 실루엣 및 레일 대상 선택 표현 변경
- 카드 프레임 아트 또는 새 선택 테두리 스프라이트 제작
- 손패 호버 크기·위치, 레일 배치 규칙 또는 코어 데이터 변경
- 새 외부 패키지 추가

## 3. 선택 외곽선

### 3.1 프리팹 구조

`CardView.prefab` 루트의 기존 카드 프레임 `Image`에 Unity uGUI `Outline` 효과를 직렬화한다.
현재 전체 Rect를 덮는 빈 `SelectionOutline` 자식 `Image`는 선택 색을 더 이상 그리지 않으며 제거한다.
`CardView`는 `[SerializeField] private Outline` 참조를 받아 프리팹에 저장된 컴포넌트만 제어한다.

런타임에 선택용 GameObject를 만들거나 프레임·에셋을 경로로 탐색하지 않는다. 외곽선 두께와
`useGraphicAlpha`는 프리팹의 `Outline` 설정으로 저작한다.

### 3.2 상태 동작

- `None`: `Outline.enabled = false`.
- `Primary`: 외곽선을 활성화하고 기존 황금색 선택 색을 사용한다.
- `Secondary`: 외곽선을 활성화하고 기존 푸른색 선택 색을 사용한다.
- 선택 상태 전환은 루트 프레임 `Image.color`를 변경하지 않는다.
- 카드 내부의 아트, 이름판, 설명판과 소유자 칩 색을 변경하지 않는다.

따라서 손패에서 실행 카드나 조작 카드를 선택해도 푸른색은 프레임 외곽 효과에만 나타난다.
배치 비행 복제본은 `Bind()`에서 선택 상태가 `None`으로 초기화되므로 선택 외곽선 없이 이동한다.

## 4. 비행 경로

### 4.1 좌표 기준

경로는 비행 카드가 속한 오버레이 레이어의 로컬 좌표로 계산한다.

- 카드 출발점: 호버 자세로 고정된 손패 카드 중심
- 목표점: 레일 배치 실루엣 중심
- `12시`: 오버레이의 위쪽, 즉 카드 윗변의 정방향
- `3시`: 오버레이의 오른쪽
- 손패는 목표 레일보다 아래에 있다는 전투 화면 배치를 전제로 한다.

목표가 없거나 손패 카드가 유효하지 않은 기존 실패 경로는 그대로 선택을 안전하게 종료한다.

### 4.2 첫 번째 Bézier — `12시 → 2시 → 10시 → 9시`

첫 구간은 3차 Bézier를 사용한다.

- `P0`: 손패 카드 중심
- `C1`: `P0`에서 위쪽으로 올린 제어점. 출발 접선을 12시로 만든다.
- `P3`: 목표 실루엣의 오른쪽이면서 하단 경계보다 위인 접근점
- `C2`: `P3`보다 더 오른쪽에 있고 `P3`와 같은 높이인 제어점

`C1`과 `C2`가 카드를 먼저 위·오른쪽으로 부풀린 뒤 왼쪽으로 되감는다. 진행 방향은 자연스럽게
12시에서 2시를 거쳐 10시와 9시로 바뀐다. `C2`와 `P3`의 높이를 같게 두어 첫 구간의 마지막
접선은 정확히 9시 방향이 된다.

### 4.3 두 번째 Bézier — `9시 → 12시` 안착

두 번째 구간은 2차 Bézier를 사용한다.

- 시작점: 첫 구간의 `P3`
- 제어점: 목표점과 같은 X, `P3`와 같은 Y
- 끝점: 목표 실루엣 중심

이 구조는 시작 접선을 9시, 도착 접선을 12시로 만든다. 두 구간은 `P3`에서 같은 9시 접선을
공유하므로 위치와 방향이 꺾이지 않는다. 두 번째 구간의 모든 점은 접근점과 목표점이 만드는 사각형
안에 있으므로 실루엣의 하단 경계보다 아래로 내려가지 않는다.

접근점의 세로 오프셋은 목표 카드 높이의 비율로 계산하고 절반 높이 미만으로 제한한다. 이에 따라
9시 지점은 항상 실루엣 하단 안쪽에 남는다.

### 4.4 DOTween과 회전

`ExecutionRailView`가 기존처럼 비행 sequence를 소유한다. 직선 `DOMove`와 별도 기울기 tween은
제거하고, DOTween이 정규화 진행률 `0..1`을 보간하도록 한다.

매 업데이트에서 다음을 함께 적용한다.

1. 현재 구간의 Bézier 위치를 평가해 비행 카드 위치를 갱신한다.
2. 같은 구간의 Bézier 미분값으로 진행 접선을 구한다.
3. 카드의 로컬 위쪽이 접선을 향하도록 Z축 회전을 갱신한다.
4. 기존 시작 크기에서 레일 카드 크기까지 축소한다.

두 구간의 전환 비율, 첫 구간 상승 높이, 오른쪽 팽창량, 접근점의 가로·세로 오프셋과 전체 지속
시간은 `ExecutionRailView`의 `[SerializeField] private` 튜닝값으로 둔다. 전환 비율은 두 구간의
위치와 접선을 바꾸지 않고 속도 배분만 조절한다.

도착점의 Bézier 접선이 12시이므로 카드 회전은 자연스럽게 정방향에 도달한다. 완료 프레임에서는
부동소수점 오차를 없애기 위해 목표 위치, 목표 스케일과 목표 회전을 한 번 정확히 적용한다.

## 5. 데이터 및 생명주기

기존 배치 순서는 유지한다.

```text
실루엣 클릭
  -> 중복 입력 차단
  -> 세션 배치 한 번 적용
  -> 원본 손패 카드와 실루엣 숨김
  -> 두 구간 Bézier 이동 + 접선 회전 + 축소
  -> 목표 위치·회전·크기 스냅
  -> 비행 복제본과 sequence 정리
  -> 선택 머신 성공 처리
  -> RefreshAll 한 번 호출
```

세션 적용 실패에는 tween을 만들지 않는다. 활성 sequence가 강제 종료되면 기존 완료 가드가 성공
정리와 UI 갱신을 한 번만 실행한다. `DOTween.KillAll()`을 사용하지 않고 레일 뷰가 소유한 sequence만
종료한다.

## 6. 테스트

### Unity EditMode

- `CardView` 프리팹은 선택용 `Outline` 참조를 가진다.
- Secondary 선택 시 외곽선만 활성화되고 색은 푸른색이다.
- 선택해도 루트 프레임 `Image.color`는 변경되지 않는다.
- None으로 복원하면 외곽선이 비활성화된다.
- 손패 선택 카드가 기존 회전 없는 호버 자세를 유지한다.
- 비행 시작점의 위치와 회전은 손패 카드와 일치한다.
- 첫 Bézier 시작 접선은 12시이고 첫 구간 끝 접선은 9시다.
- 최종 Bézier 시작 접선은 9시, 도착 접선은 12시다.
- 최종 구간을 여러 시점에서 샘플링해 실루엣 하단 경계 아래로 내려가지 않음을 확인한다.
- sequence 완료 후 위치·회전·스케일이 목표와 일치하고 완료 콜백은 한 번만 호출된다.
- 적용 거부, 연속 클릭, 선택 취소와 기존 레일 상세 호버 테스트가 계속 통과한다.

### 수동 플레이

- 선택된 손패 카드의 프레임 외곽만 푸르게 보이고 카드 내부에는 푸른 면이 생기지 않는다.
- 손패 카드가 아래에서 출발해 `3`의 윗고리처럼 위·오른쪽으로 부풀었다가 왼쪽으로 감긴다.
- 카드 윗변이 이동 방향을 따라 12시, 2시, 10시, 9시 방향으로 자연스럽게 바뀐다.
- 9시 이후 실루엣 아래로 내려가지 않고 12시 정방향으로 풀리며 안착한다.
- 최종 레일 카드 전환 시 위치·회전·크기 점프가 보이지 않는다.
