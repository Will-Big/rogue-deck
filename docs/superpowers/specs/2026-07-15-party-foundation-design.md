## 0. 이 문서의 위치

이 문서는 **파티 구조 / 카드 소유 / 죽음 규칙 / 인원 경제** 층의 합의를 담는다. 이 세션의 출발점이었던 "전투 턴 루프(손패+에너지)의 StS 유사성" 문제는 **미해결로 남아 있다** (§8 참고 — 진단은 공유됐고, 자동 배치 방향은 탐구 후 보류).

| 공용 카드는 파티 보관함 소유, 장착제 | 공용(범용) 카드도 **획득 시 캐릭터에 귀속** |

## 1. 게임 구조 (확정)

1. **런 단위 게임.** 런 하나에 집중한다. 런을 넘는 영속 로스터·파워 이월은 없다.
2. **파티는 최대 3인, 보유 = 전원 전투 참여.** 벤치 개념 없음.
3. **1인으로 시작**하며, 맵의 **특별 노드**를 통해서만 충원한다.
4. **캐릭터 = 카드 풀.** 한 캐릭터만으로는 온전한 덱을 만들기 어렵다. 시너지가 발생하는 캐릭터들을 파티에 포함시키는 것이 곧 덱 빌딩이다.
5. 1~2인 플레이를 원칙적으로 막지 않는다. 다인 파티는 금지·페널티가 아니라 **혜택(§3)으로 권장**한다. 소수 인원의 대가는 아쉬운 카드 풀 그 자체다.

## 2. 카드 소유 (확정)

1. **모든 카드는 획득 시 소유 캐릭터가 지정된다** (캐릭터 귀속).
2. **모든 카드는 정확히 한 캐릭터의 개별 카드풀에 속한다. 공용 카드는 없다.**
3. 일반 보상에는 현재 파티에 포함된 캐릭터가 소유한 카드만 등장한다.
4. `범용`은 여러 덱에서 활용 가능한 설계 역할이며 공용 소유권을 뜻하지 않는다.
5. **운명 카드(순서 조작)도 캐릭터에 귀속된다.**
6. 전투 덱 = 파티원들의 카드 합집합 (합성 덱).

카드 소유권, 범용·핵심 설계 역할과 일반 보상의 상세 기준은
[`character-card-pools-design`](2026-07-20-character-card-pools-design.md) §1과 §4를 따른다.

## 3. 파티 인원 경제 (확정)

- **인원 비례 혜택**으로 다인 파티를 권장한다:
  - 턴당 드로우: 1인 3장 / 2인 4장 / 3인 5장 *(초안 수치 — 시뮬레이션으로 조율)*
  - 최대 HP: 캐릭터마다 **개별 HP** 존재(초안: 25) — 인원 증가 = 파티 총 HP 증가. 개별 사망 가능.
- 운명력은 당분간 인원과 무관.
- **2인 이하 상태에 보정을 주지 않는다.** 보정을 주면 소수 인원 유지가 최적화 대상이 된다. 카드 게임에서 적은 인원 = 얇은 풀 = 높은 압축률이라는 은근한 이점이 이미 있으므로, 드로우 비례 스케일로 상쇄한다. 별도 페널티도 없다 — 비례만 존재한다.

## 4. 죽음 규칙 (확정)

- **톤: Darkest Dungeon.** 죽음은 무겁고 실재하며 부활은 없다.
- 동시에 설계 목표: **죽음이 "쌓아온 덱 붕괴 → 리셋 트리거"가 되어서는 안 된다.** 손실은 실재하되, 핵심은 건질 수 있고, 바닥이 런 포기까지 뚫리지 않게.
- **치명 피해 시 즉사하지 않는다.** HP 1로 **1회 버틸 수 있다.** *(버팀 기회의 리셋 주기 — 전투당/런당 — 은 미정)*
- **사망 시 카드 처리 (전투 중):**
  - 덱·손패에서 그 캐릭터의 카드(운명 카드 포함) **즉시 제거**
  - 미래 영역에 이미 배치된 카드는 **무효화** — 기존 카드 스코프 상태(기절/무효화) 메커니즘 재사용
- 전멸 = 패배. 1인이라도 생존하면 전투 계속.
- **유산 시스템 (퇴장 후):** 캐릭터가 대체·제거되거나 사망하면 그 카드 일부를 유산으로 남길 수 있다.
  유산은 비용을 지불해 미공개 후보 최대 3장을 보고 반드시 1장을 선택하며, 공개된 후보는 다음
  탐색에서 제외된다. 같은 캐릭터를 반복 탐색할수록 비용이 누적 증가한다. 상세 규칙과 소유권 예외는
  [`character-card-pools-design`](2026-07-20-character-card-pools-design.md) §4를 따른다.
- **충원:** 특별 노드에서만. 신입의 상태 구체화는 미정 *(제시된 안: 기본 키트 + 현재 진행도에 비례한 "경력 드래프트" — 카드 선택 연속 수행)*

## 5. 전투 규칙 — 타겟팅과 대형 (확정)

1. 파티(그리고 적)에게는 **배치(대형) 순서**가 있다 (Darkest Dungeon 스타일의 전/후 개념). 전투 씬에서 캐릭터 배치를 새로 잡아야 한다.
2. **적의 공격은 모두 타임라인에 예고**되며, 타겟팅 규칙이 카드에 명시된다:
   - "가장 앞에 있는 대상을 공격합니다" (+추가효과 or not)
   - "가장 뒤에 있는 대상을 공격합니다" (+추가효과 or not)
   - "무작위 대상을 공격합니다" (+추가효과 or not)
3. **방어·지원 카드도 대상이 정해져 있다.** 플레이어는 대상을 유의하며 사용해야 한다. 플레이어 카드는 직접 대상 지정형도 가능하다.
4. **배치 변경 카드가 존재한다** — 자신의/상대의 대형을 바꾸는 카드 (플레이어·적 양측, DD 스타일).
5. 무작위 타겟은 기존 rngSeed 체계로 결정론을 유지한다.

## 6. 첫 구현 범위 (확정)

- **시작 캐릭터 1명 + 동료 1명** — 2인 파티 검증 먼저, 3인은 다음 단계.
- 기존 카드(손목 베기, 표식 새기기, 연쇄 베기 등)를 시작 캐릭터에게 재배속.
- 동료용 신규 카드 **4~6장**.
- 전투 씬에 캐릭터 대형 표시 — 기존 배틀 스크린 스켈레톤 위에.

## 7. 설계 원칙 (이번 세션에서 합의)

- **기본 규칙은 플레이어를 벌하지 않는다.** 플레이어가 불쾌하지 않게 느끼는 것이 공정성보다 우선이다. 기본 규칙에 플레이어를 얽매는 요소를 넣지 않는다. 압박은 적 설계에서만 오고, 유도는 보상으로만 한다.
- **죽음의 손실 크기는 가능한 한 플레이어의 선택이 결정한다** — 카드를 누구에게 귀속시켰는가가 곧 위험 배분이다.
- 전투의 핵심 정체성 = **실행 순서 조작(운명 조작)**. 행동 재배열 + 턴 종료 시 순차 해석은 플레이테스트에서 재미가 검증됐고 유지한다.

## 8. 미정 / 보류 (다음 세션 재개 지점)

| 항목 | 상태 |
|---|---|
| **전투 턴 루프의 StS 유사성** | 진단 공유됨: "손패에서 뭘 낼지 고민하는 순간"이 가장 StS 같다. "운명이 자동 배치하고 플레이어는 재배열만 한다" 방향을 탐구했으나 재미 확신이 없어 **보류**. 재배열+순차 해석은 유지 확정 |
| 인계 카드 서사 표시(유품) | 미정 |
| 신입 합류 구체화 | 경력 드래프트 안 제시 상태 |
| 파티원 고유 효과 | "각자 조작 동사를 가져온다" 방향은 긍정적. **액티브 vs 유물형 패시브** 미정 |
| 캐릭터 시너지 설계 | [`character-card-pools-design`](2026-07-20-character-card-pools-design.md)에서 공통 규칙 확정, 개별 카드 설계 전 |
| 죽음 예지 연출 | "캐릭터를 죽이는 사건은 타임라인에 미리 보인다" — 제안 상태, 미확정 |
| 치명 피해 버팀의 리셋 주기 | 전투당 1회 vs 런당 1회 — 미정 |
| 3인 파티 콘텐츠 | 2인 검증 후 |

## 9. 코어 구현 가이드 (참고 — 계획서 작성 시 상세화)

- `CombatState`의 단일 `playerHp` → **파티원 목록** (개별 HP, 대형 순서, 생존/버팀 상태)
- `OwnedCard`에 소유 캐릭터 참조 추가
- 타겟팅 셀렉터(FrontMost / BackMost / Random)를 효과 파라미터로 — 기존 효과 핸들러 레지스트리 확장, 중앙 코드 무수정 원칙 유지
- 대형 변경 = 신규 효과/개입 액션 핸들러 (키 레지스트리)
- 사망 처리: 기존 카드 스코프 무효화 상태 재사용, 덱·손패 제거는 덱 루프 레이어
- 드로우 수 = f(생존 인원) — 어디에도 상수를 하드코딩하지 않는다 (운명력 변수화와 동일 원칙)
- 검증: 헤드리스 시나리오 — 2인 파티의 타겟팅/개별 사망/치명 버팀/드로우 스케일/사망 시 카드 제거·무효화 회귀 테스트
