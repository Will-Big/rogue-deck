# Fate Weaver — 플레이어 캐릭터 7종 카드풀 초안

- 작성일: 2026-07-20
- 상태: 컨셉·밸런스 재설계를 위한 전체 초안
- 범위: 캐릭터 7종, 캐릭터별 실행 카드 12장 + 조작 카드 4장

## 1. 목적

이 문서는 Fate Weaver의 파티 덱빌딩 구조에 맞는 플레이어 캐릭터 7종과 카드풀을 제안한다.
완성된 밸런스 표가 아니라, 캐릭터의 플레이 감각과 파티 간 시너지 경로를 폭넓게 검토하기 위한
디자인 원안이다. 비용·피해·방어·상태 수치는 상대적인 성공 폭을 보여주는 초안이며 이후 플레이테스트로
교체한다.

핵심 원칙은 다음과 같다.

1. 캐릭터 하나가 덱 컨셉의 생성·증폭·소비를 전부 완성하지 않는다.
2. 각 캐릭터는 두 컨셉을 가지며, 각 컨셉은 이웃 캐릭터와 공유한다.
3. 실행 카드는 낮은 기본값과 강한 위치·순서 조건을 가진다.
4. 조작 카드는 직접 피해보다 실행선·대형·대상·손패·상태를 바꾸는 데 집중한다.
5. 강한 연계는 다른 캐릭터의 카드, 같은 대상, 실행 위치 등 둘 이상의 조건을 요구한다.

## 2. 전체 구조

```text
전열대장 ─대형─ 황야추적자 ─표식─ 검무가 ─연계─ 운명점술사
   │                                                    │
  방벽                                                 시차
   │                                                    │
혈갑기사 ─생사선─ 장송인 ─부식─ 역병의사 ────────────────┘
```

| 캐릭터 | 컨셉 A | 컨셉 B | 주 역할 |
|---|---|---|---|
| 전열대장 | 방벽 | 대형 | 피격 대상과 아군 대형을 정리하고 방어를 예약한다 |
| 황야추적자 | 대형 | 표식 | 후열을 확보하고 적 대형·공격 대상을 조정한다 |
| 검무가 | 표식 | 연계 | 표식을 소비하고 다른 캐릭터의 실행 카드 뒤를 잇는다 |
| 운명점술사 | 연계 | 시차 | 실행선의 간격을 봉합하고 빠른 카드와 늦은 카드를 모두 지원한다 |
| 역병의사 | 시차 | 부식 | 지연을 가치로 바꾸고 독을 축적한다 |
| 장송인 | 부식 | 생사선 | 독을 이전·수확하고 위독한 아군의 마지막 행동을 보존한다 |
| 혈갑기사 | 생사선 | 방벽 | 낮은 HP와 소진되는 방어를 공격 자원으로 전환한다 |

### 2.1 카드풀과 시작 카드

각 캐릭터의 카드풀은 총 16장이다.

- 실행 카드 12장: 기본 공격 1, 기본 방어 1, 컨셉 카드 8, 연결 카드 2
- 조작 카드 4장: 입문 조작 2, 고급 조작 2
- `★`는 시작 후보를 뜻한다.
- 시작 덱은 기본 공격 1장, 기본 방어 1장, `★ 실행` 중 무작위 1장,
  `★ 조작` 중 무작위 1장으로 구성한다.

### 2.2 표기

| 표기 | 의미 |
|---|---|
| 현행 | 현재 효과·조건·조작 문법으로 표현 가능 |
| 조건 | 새 `Condition`이 필요함 |
| 효과 | 새 `IEffectHandler` 또는 효과 payload가 필요함 |
| 상태 | 새 상태 행동 또는 상태 훅이 필요함 |
| 조작 | 새 `IInterventionActionHandler` 또는 조작 payload가 필요함 |

조작 카드는 손에서 운명력을 지불해 즉시 해결되고 실행순서를 갖지 않는다. 별도 언급이 없는 실행 카드의 적 대상은
**해결 시점의 적 전열**이며, 실행 카드를 배치할 때 직접 대상을 고르지 않는다. 아군을 지정하는 실행
효과는 카드 문구에 적힌 규칙(예: HP가 가장 낮은 아군)으로 자동 선택한다. 조작 카드만 플레이 과정에서
엔티티·손패·미래 영역의 대상을 직접 고를 수 있다.

## 3. 공용 키워드 초안

### 방어

이번 턴에 받는 피해를 수치만큼 막는다. 카드 설계에서는 여러 방어 부여가 합산되는 것을 전제로 했지만,
현재 `StatusBag.Add`의 동일 키 재적용은 교체이므로 실제 구현 전에 합산·교체 규칙을 확정해야 한다.

### 표식 X

표식을 부여한 캐릭터가 아닌 다른 캐릭터의 **표식 보상 카드**가 대상에게 적중할 때 표식 1을 소비하고
그 카드의 추가 효과를 활성화한다. 일반 피해 카드에는 자동 보너스가 없다. 표식에는 부여자 ID가 기록되어야
한다.

### 협공

직전에 정상 실행된 플레이어 카드가 현재 카드와 다른 캐릭터 소유이며, 두 카드가 같은 적을 대상으로 했다면
성공하는 조건이다. 취소된 카드는 건너뛴다.

### 조건 보호

카드 인스턴스에 부여되는 1회성 상태다. 적의 `조건 보상 무효`를 한 번 막고 함께 소비된다. 조건 자체를
자동 성공시키지는 않으므로 실행선 조작은 여전히 필요하다.

### 시차

별도 자원이 아니라 실행순서 변경, 가속, 둔화, N번째 이내·이후, 첫·마지막 실행 조건을 묶는 설계 용어다.
낮은 실행순서가 먼저 발동한다.

### 독 X

턴 종료 시 X만큼 피해를 주고 독이 1 증가한다. 독 피해 자체는 표식을 소비하거나 카드 조건을 만족시키지
않는다. 장기전에서 무한히 증가할 수 있으므로 실제 밸런스 단계에서 최대치·정화·전투 길이를 함께 검토한다.

### 생사선

캐릭터의 현재 HP가 튜닝된 기준 이하이거나, 이번 전투에 죽음의 문턱 충전을 소비했다면 생사선 상태로
간주한다. HP 기준은 상수로 박지 않고 캐릭터·전투 튜닝 데이터로 둔다.

### 연명

이번 턴의 다음 치명 피해를 받으면 HP 1로 버티고 사라진다. 전투 기본 죽음의 문턱 충전보다 먼저
소비한다. 중첩되지 않고 지속시간만 갱신한다.

### 유언

카드 인스턴스에 부여되는 상태다. 소유자가 카드 실행 전에 사망해도 해당 카드는 한 번 정상 실행된 뒤
유언을 소비한다. 소유자를 대상으로 하는 `Self` 효과는 사망 상태에서 유효하지 않으므로 해당 효과만
건너뛰고, 적 대상 효과는 실행한다.

황야추적자의 위치 보상이나 혈갑기사의 방어 소비가 있어야 공격적인 가치가 생긴다.

제한하여 검무가나 다른 표식 보상 카드와 함께할 때 집중 공격이 완성되게 한다.

### 4.3 검무가 — 표식 · 연계

검무가는 표식을 공격 보상으로 소비하고 다른 캐릭터가 만든 흐름을 잇는다. 표식을 대량 생성하거나
실행선을 자유롭게 정리하지 못하므로 황야추적자와 운명점술사가 서로 다른 방식으로 부족한 절반을 채운다.

| 2 | 흘려내기 | 실행 | 1/3 | 자신이 방어 3을 얻는다. | 현행 |
| 3 | ★ 표적 베기 | 실행 | 1/4 | 피해 2. 다른 캐릭터의 표식 1을 소비하면 대신 피해 7. | 상태·효과 |
| 4 | ★ 틈새 찌르기 | 실행 | 1/5 | 피해 2. 표식 1을 소비하면 대상에게 취약을 1턴 부여한다. | 상태·효과 |
| 5 | ★ 이어 베기 | 실행 | 1/5 | 피해 2. 직전 플레이어 카드가 다른 캐릭터 소유면 대신 피해 6. | 조건 |

## 5. 파티 시너지 예시

아래는 정답 파티가 아니라 카드 상호작용을 확인하기 위한 예시다.

### 전열대장 + 황야추적자

`긴급 교대`나 `어깨 교대`로 추적자를 후열에 보내 `후열 사격`을 활성화한다. 추적자는
`몰아붙이는 사격`으로 위험한 적을 뒤로 보내고, 전열대장은 그 적의 카드들을 `전열 압박`으로 늦춘다.

### 황야추적자 + 검무가

추적자가 `신호 화살`로 표식을 만들고 `약점 포착`으로 서로 다른 소유자의 공격 대상을 통일한다.
검무가는 `표적 베기`, `교차 참격`으로 표식과 협공을 각각 소비한다.

### 검무가 + 운명점술사

검무가의 강한 연계 카드는 다른 캐릭터 카드와 인접해야 한다. 점술사의 `운명의 봉합`과 검무가의
`합 맞추기`는 서로 다른 범위의 실행선 문제를 해결하지만 어느 한 장도 전체 실행선을 완성하지 않는다.

### 운명점술사 + 역병의사

점술사는 빠른 `느린 처방`을 더 앞당겨 적의 다음 턴을 늦추거나, `숙성 완료`를 뒤로 보내 늦은 조건을
만든다. 역병의사의 `투약 연기`는 점술사의 상태 카드에도 적용되어 시차 선택지를 공유한다.

### 역병의사 + 장송인

역병의사는 여러 적에게 독을 만들고 증가시키지만 자유로운 이전 능력은 부족하다. 장송인은 독을
취약·방어·연명으로 바꾸거나 위험한 적 하나에 모아 파티의 다음 공격 목표를 만든다.

### 장송인 + 혈갑기사

혈갑기사가 자해와 낮은 HP 조건을 사용하고, 장송인이 `연명`과 `유언`으로 실패 비용을 제한한다.
혈갑기사 혼자서는 죽음 위험을 안정적으로 관리하지 못하고 장송인 혼자서는 생사선 조건을 능동적으로
만들기 어렵다.

### 혈갑기사 + 전열대장

전열대장은 방어를 공급하고 혈갑기사는 `방패 분쇄`, `균열 난 갑주`로 방어의 소진을 공격 가치로
바꾼다. 방어를 전부 소비하면 이후 적 공격에 노출되므로 매 턴 자동으로 선택할 수 있는 조합은 아니다.

### 비인접 조합

- 전열대장 + 운명점술사: `엄호 지점`과 순서 조작으로 원하는 시점에 방어를 발생시킨다.
- 황야추적자 + 역병의사: 독이 쌓인 적을 전열로 끌어내고 그 적의 카드를 늦춘다.
- 검무가 + 혈갑기사: 혈갑기사의 빠른 위험 카드가 검무가의 다른 소유자 연계를 연다.
- 운명점술사 + 장송인: 유언 카드의 실행을 늦게 보존하거나, 위험해지기 전에 앞으로 옮긴다.

## 6. 신규 규칙 구현 목록

이 절은 구현 계획이 아니라, 카드 재설계 시 비용을 판단하기 위한 목록이다.

### 6.1 조건

- 소유자의 현재 대형 위치: 전열, 후열, N번째
- 이번 턴 앞서 아군·적 대형이 변경됐는지
- 대상이 특정 상태를 가졌는지와 상태 부여자
- 직전 정상 실행 카드의 소유자가 다른지
- 협공: 다른 소유자 + 같은 대상
- N번째 이후 실행, 이후 적 카드 존재 여부
- 소유자 또는 임의 아군이 생사선인지
- 이번 턴 죽음의 문턱이 소비됐는지
- 해결 시 방어 잔량 또는 앞서 방어가 감소했는지

### 6.2 실행 효과

- 아군·적을 전열/후열/상대 위치로 이동·교환
- 자신 이외 아군, HP 최저 아군, 모든 다른 아군 대상으로 효과 적용
- 표식의 부여자 기록·소비·카드별 보상 활성화
- 다음 `다른 소유자` 카드에 피해 보너스나 상태 부여
- 기존 상태 수치 증가·감소·이전·소비
- 독의 턴 종료 피해와 성장
- 일시적 연명 부여와 죽음의 문턱 우선순위 처리
- 방어 소비량·잔량을 피해나 이전량으로 변환
- 제한된 자해와 자해로 인한 죽음의 문턱 처리 규칙

### 6.3 조작 대상과 payload

현재의 단일 실행 카드 대상 외에 다음 대상 모델이 필요하다.

- 손에 있는 카드 1장 또는 여러 장
- 미래 영역 카드 여러 장과 선택 순서
- 파티원과 적 엔티티
- 동일 소유자의 모든 미래 카드
- 상태가 있는 모든 적이 소유한 카드
- 선택 대상 없음 + 전투 RNG 무작위 대상
- 카드의 임시 비용·실행순서·효과 수치·대상 변경

무작위 조작은 반드시 `CombatState.Rng`를 사용하고, UI는 조작마다 요구되는 대상 종류와 최소·최대 개수를
조작 데이터에서 읽어야 한다.

### 6.4 상태와 해석 훅

- 엔티티 턴 종료 훅: 독
- 카드 실행 직전 훅: 엄호, 위험한 앞당김
- 카드 조건 보상 보호·무효화
- 소유자 사망 취소 예외: 유언
- 치명 피해 직전 훅: 연명
- 방어 감소 관찰: 균열 갑주
- 상태의 출처 캐릭터 ID: 표식

### 6.5 이벤트 타임라인

표현 레이어가 코어 상태를 직접 뒤지지 않도록 다음 결과는 이벤트로 노출해야 한다.

- 대형 이동·교환
- 표식·독의 부여, 소비, 이전, 턴 종료 발동
- 방어 획득·소비·이전
- 카드의 임시 변형과 대상 변경
- 연명 발동과 유언 실행
- 다중 카드 조작 전후의 실행선 변화

## 7. 재설계 체크리스트

각 캐릭터와 카드를 다시 다듬을 때 다음을 확인한다.

1. 기본 공격·방어·시작 후보만으로 캐릭터의 두 컨셉이 보이는가?
2. 시작 조작 카드가 시작 실행 카드의 조건을 열 수 있지만 매번 자동 성공시키지는 않는가?
3. 캐릭터 혼자 핵심 상태의 생성·증폭·소비를 모두 수행하지 않는가?
4. 조작 카드가 직접 피해보다 미래 영역·대형·대상·손패를 바꾸는가?
5. 강한 실행 카드가 우연한 자동 정렬만으로 자주 성공하지 않는가?
6. 조작 대상 수와 비용이 실제 UI에서 이해 가능한가?
7. 무작위 대상 카드가 실패 대상 없이 결정론적으로 작동하는가?
8. 캐릭터 사망 시 해당 소유 카드 제거 규칙과 유언이 모순되지 않는가?
9. 독·표식·방어처럼 반복 가능한 상태가 장기전에서 무한 성장하지 않는가?
10. 인접하지 않은 캐릭터 조합에서도 최소 하나의 의미 있는 상호작용이 존재하는가?
11. 1인 파티에서도 시작 실행·조작 카드가 완전히 무효가 되지 않는가?
