## 1. 목적

카드 본문에서 `가장 앞의`, `전열에서 두 번째`, `가장 뒤의`와 같은 대상 문구를 제거한다. 유닛에게
적용되는 카드 능력은 개별 유닛을 직접 선택하지 않고 아군 또는 적군 대형의 **위치 범위**를 지정한다.
카드의 현재 사용자를 지정하는 능력은 그 사용자가 속한 진영의 특수 범위인 **자신**을 사용한다. 카드
프레임의 별도 대상 칸이 진영과 범위를 그림으로 표시하고, 본문은 능력만 설명한다.

이 문서는 [파티 기반 전투](2026-07-15-party-foundation-design.md) §5의 직접 선택·무작위·위치 선택
규칙을 대체한다. 현재 구현에 남아 있는 직접 선택과 대상 문구 생성은 이 설계에 맞추는 후속 작업의
대상이며, 이 문서에서는 코드와 카드 콘텐츠를 변경하지 않는다.

## 2. 위치 대상의 기본 계약

아군과 적군은 서로 독립된 대형이다. 유닛 대상 능력은 특정 유닛의 식별자를 미리 지정하지 않고 다음
다섯 위치 범위 또는 특수 범위 `자신`을 사용한다.

| 위치 범위 | 의미 |
|---|---|
| 자신 | 현재 이 카드를 사용하는 유닛 1명. 대형 위치와 무관하며 그 사용자가 속한 진영에 사용 |
| 앞 하나 | 해당 진영의 생존 대형에서 가장 앞의 유닛 최대 1명 |
| 앞 둘 | 해당 진영의 생존 대형에서 앞쪽 유닛 최대 2명 |
| 뒤 하나 | 해당 진영의 생존 대형에서 가장 뒤의 유닛 최대 1명 |
| 뒤 둘 | 해당 진영의 생존 대형에서 뒤쪽 유닛 최대 2명 |
| 모두 | 해당 진영의 생존 유닛 전부 |

플레이어의 일반 카드에서 현재 사용자는 그 카드를 소유한 캐릭터다. 유산 카드는 원래 소유권 표기를
유지하더라도 현재 카드를 물려받은 계승자가 사용자가 된다. 따라서 유산 카드의 `자신`은 원래 소유자가
아니라 현재 계승자를 가리킨다. 적의 실행 카드에서는 그 카드를 실행하는 적 유닛이 현재 사용자다.

직접 선택, 무작위 선택, 정확히 두 번째 또는 가운데 위치 선택, HP·상태·수치 우선 선택은 유닛 대상
문법으로 사용하지 않는다. 가운데 유닛에게 영향을 주려면 대형을 이동시키거나 앞·뒤 범위가 둘 이상을
포함하도록 설계한다. `자신`은 플레이어가 유닛을 직접 고르는 선택지가 아니라 카드의 현재 사용자로
자동 결정되는 고정 대상이므로 이 금지에 해당하지 않는다.

드로우, 운명력 획득, 덱 조작처럼 유닛에게 적용되지 않는 능력은 위치 범위를 갖지 않는다.

## 3. 실행 시 대상 확정

대상은 카드 배치 시점이 아니라 **카드 실행 시작 시점**에 확정한다.

1. 카드 실행이 시작되면 진영별 생존 유닛을 현재 대형 순서로 읽는다.
2. 카드가 지정한 위치 범위에 따라 서로 다른 생존 유닛의 집합을 만든다. `자신`이면 대형 위치 대신
   카드의 현재 사용자 1명을 선택한다.
3. 요구하는 수보다 생존 유닛이 적으면 존재하는 유닛만 포함한다.
4. 부족한 수를 채우기 위한 반복·되감기·중복 선택은 하지 않는다.
5. 진영별로 확정한 대상 집합은 카드 실행이 끝날 때까지 유지한다.

따라서 유닛이 한 명뿐일 때 `앞 둘`, `뒤 둘`, `모두`는 모두 그 한 명을 선택하지만 효과를 한 번만
적용한다. 카드 자체가 별도의 반복 발동을 명시한 경우에만 같은 유닛에게 효과가 다시 발생할 수 있다.

앞선 카드가 유닛을 이동시키거나 사망시켰다면 이후 카드는 변경된 생존 대형을 기준으로 대상을
확정한다. 반면 한 카드가 실행되는 도중 이미 확정된 대상을 이동시켜도 그 카드의 나머지 대상 능력은
같은 유닛에게 적용된다. 대상이 카드 실행 도중 사망하면 그 유닛을 향한 남은 효과는 적용하지 않으며
같은 위치나 다른 위치의 유닛으로 대체하지 않는다.

## 4. 카드 안의 진영별 범위

카드 한 장은 아군 진영과 적군 진영에 서로 다른 범위를 지정할 수 있다.

- 적 관련 능력은 적군 위치 범위 또는 적이 실행하는 카드의 `자신`을 사용한다.
- 아군 관련 능력은 아군 위치 범위 또는 아군이 실행하는 카드의 `자신`을 사용한다.
- 카드 한 장의 현재 사용자는 한 명이므로 아군과 적군에 `자신`을 동시에 지정할 수 없다.
- 같은 진영에 적용되는 모든 대상 능력은 같은 위치 범위와 같은 확정 대상 집합을 공유한다.
- 한 카드 안에서 같은 진영의 능력마다 서로 다른 위치 범위를 지정하지 않는다.

예를 들어 한 카드는 앞의 적에게 피해를 주면서 뒤의 아군에게 방어를 부여할 수 있다. 이때 적군
대상과 아군 대상은 실행 시작 시 각 진영의 생존 대형에서 독립적으로 확정한다.

## 5. 대상 칸

대상 칸은 최대 한 줄이다. 아군은 왼쪽, 적군은 오른쪽에 두며 양 진영의 전열이 가운데를 향한다.
진영은 작은 고정 문양과 색상을 함께 사용하고 색상만으로 구분하지 않는다.

```text
[아군 문양] 아군 위치 범위 │ 적군 위치 범위 [적군 문양]
```

- 한쪽 진영만 사용하는 카드는 사용하는 진영과 위치 범위만 표시한다.
- 양쪽 진영을 사용하는 카드는 한 줄에 두 위치 범위를 함께 표시한다.
- 유닛 대상 능력이 없는 카드는 대상 칸에 `없음`을 표시한다.
- 사용하지 않는 진영을 별도의 `없음` 행으로 만들지 않는다.

위치 그림은 실제 유닛 수나 빈 슬롯을 나타내지 않는다. 밝은 마름모는 범위에 포함되는 앞·뒤 유닛
수를, 이어지는 레일은 나머지 대형을 뜻한다. `모두`는 레일 전체가 켜진 상태로 표현한다. `자신`은
대형 위의 위치로 오해하지 않도록 레일 없이 이중 원 `◎` 하나로 표시한다.

| 위치 범위 | 아군 진영 | 적군 진영 |
|---|---|---|
| 자신 | `◎` | `◎` |
| 앞 하나 | `━━━━◆` | `◆━━━━` |
| 앞 둘 | `━━━◆◆` | `◆◆━━━` |
| 뒤 하나 | `◆━━━━` | `━━━━◆` |
| 뒤 둘 | `◆◆━━━` | `━━━◆◆` |
| 모두 | `━━━━━` | `━━━━━` |

위 문자는 의미를 설명하기 위한 표기다. 실제 프레임에서는 선택된 마름모와 전체 선택 레일이 비선택
레일과 명도·형태로 구분되어야 한다.

## 6. 능력 본문

위치와 진영은 대상 칸이 소유하므로 능력 본문에서 `가장 앞의 적에게`, `뒤의 아군에게` 같은 대상
문구를 반복하지 않는다.

양 진영에 능력이 있는 카드는 능력을 진영 문양으로 구분한다.

```text
[적군 문양] 피해 5. 독 2 부여.
[아군 문양] 방어 4.
```

같은 진영 문양 아래의 대상 능력은 대상 칸에 표시된 그 진영의 위치 범위를 공유한다. 유닛 대상이
없는 능력은 진영 문양 없이 별도 줄에 표시한다.

```text
[적군 문양] 피해 5.
카드 1장 뽑기.
```

유닛 대상 능력이 전혀 없는 카드만 대상 칸에 `없음`을 표시한다. 대상 능력과 대상 없는 능력이 함께
있다면 대상 칸에는 대상 능력의 진영과 위치 범위를 표시한다.

## 7. 카드 설계 제약과 효과

다섯 위치 범위와 `자신`은 단순한 프레임 축약이 아니라 카드 설계의 공통 제약이다.

- 중간 유닛을 노리거나 특정 아군을 보호하려면 먼저 대형을 바꾼다.
- 아군·적군 전진, 후퇴, 위치 교환, 이동 방지의 가치가 높아진다.
- 생존 유닛이 한두 명이면 여러 위치 범위가 같은 결과를 내는 것을 허용한다.
- `모두`는 유닛 수에 따라 실제 대상 수가 늘어나므로 비용과 효과량을 그 확장성에 맞춰 조정한다.
- `자신`은 위치 변경 뒤에도 같은 현재 사용자를 가리키며, 같은 카드의 나머지 아군 대상 능력도 그
  사용자에게 적용한다.
- 카드의 위치 범위와 진영 문양만 보고 실행 시작 시 어떤 대상 집합이 만들어지는지 판단할 수 있어야
  한다.

## 8. 범위 밖

- 다섯 위치 범위와 `자신`을 사용하는 개별 카드의 작성과 밸런스
- 진영 문양, 색상, 레일의 최종 그래픽
- 프리팹과 카드 프레젠테이션 구현
- 기존 직접 선택·무작위·설명 문구 데이터의 마이그레이션 계획
- 실행 카드가 아닌 다른 게임 객체를 선택하는 UI
