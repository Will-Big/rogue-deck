# 다중 대상 선택 토글 설계

## 1. 목적

둘 이상의 대상을 직접 고르는 카드에서 이미 선택한 대상을 다시 클릭하면 해당 선택을 취소할 수 있게 한다.
선택 실수를 전체 취소로 되돌리지 않고 같은 선택 흐름 안에서 바로 수정하는 것이 목적이다.

## 2. 범위

### 포함

- 아군, 적, 실행 순서 카드 등 모든 다중 대상 종류
- 선택 진행 중과 필요한 대상 수를 모두 채운 확인 대기 상태
- 선택 해제에 따른 코어 상태, 테두리, 확인 버튼 갱신
- 순수 C# 상태 전이 테스트와 Unity 표현 테스트

### 제외

- 단일 대상 카드의 즉시 완료 동작 변경
- 대상 없는 카드의 마우스 추적 배치 방식 변경
- 카드 효과, 대상 수, 자원 소비 또는 밸런스 변경
- 선택 해제 전용 버튼이나 새로운 입력 추가

## 3. 상호작용 규칙

다중 대상 선택 중 대상 클릭은 토글로 동작한다.

1. 아직 선택하지 않은 유효 대상을 클릭하면 선택 목록에 추가한다.
2. 이미 선택한 대상을 다시 클릭하면 선택 목록에서 제거한다.
3. 선택 해제된 대상은 푸른색 선택 테두리에서 황금색 후보 테두리로 즉시 돌아간다.
4. 필요한 대상 수를 모두 채우면 확인 버튼을 표시한다.
5. 확인 버튼이 표시된 상태에서 선택된 대상을 해제하면 선택 단계로 돌아가고 확인 버튼을 즉시 숨긴다.
6. 같은 대상 또는 다른 유효 대상을 다시 선택해 요구 수를 채우면 확인 버튼을 다시 표시한다.

단일 대상 선택은 첫 클릭에서 즉시 완료되므로 토글하지 않는다. 카드 플레이 요청이 거부됐을 때 선택을 지우고
다시 클릭하게 하는 기존 복구 규칙도 유지한다.

## 4. 구조

### 4.1 순수 선택 상태

`CardSelectionMachine.ClickTarget`이 다중 대상의 선택 추가와 선택 해제를 모두 소유한다.

- `PickMultipleTargets`에서 미선택 대상 클릭: 목록에 추가한다.
- `PickMultipleTargets`에서 선택된 대상 클릭: 목록에서 제거하고 같은 단계를 유지한다.
- `ReadyToConfirm`에서 선택된 대상 클릭: 목록에서 제거하고 `PickMultipleTargets`로 돌아간다.
- `ReadyToConfirm`에서 선택되지 않은 대상 클릭: 요구 개수를 이미 채웠으므로 무시한다.
- 잘못된 대상 종류와 현재 유효 후보가 아닌 대상은 기존처럼 Unity 컨트롤러에서 차단한다.

별도 `DeselectTarget` API는 추가하지 않는다. 한 번의 대상 클릭을 하나의 상태 전이로 처리해 입력 의미가
코어와 Unity 레이어 사이에서 분산되지 않게 한다.

### 4.2 Unity 선택 컨트롤러

`CardSelectionController`는 클릭 전후 선택 개수를 비교해 선택 추가 시에만 기존 중앙 강조 연출을 재생한다.
선택 해제 시에는 강조 연출을 재생하지 않고 `RefreshTargetVisuals` 결과만 반영한다.

- 선택 해제된 대상: 황금색 후보 테두리
- 여전히 선택된 대상: 푸른색 테두리
- 요구 수 미달: 확인 버튼 숨김
- 요구 수 충족: 확인 버튼 표시

아군·적 `UnitView`와 실행 순서 `RailCardView`는 기존의 `selected` 불리언 표현 API를 그대로 사용한다.
새 프리팹, 새 직렬화 필드 또는 새 UI 객체는 필요하지 않다.

## 5. 데이터 흐름

```text
선택된 대상 재클릭
  -> CardSelectionController가 유효 후보인지 확인
  -> CardSelectionMachine.ClickTarget
  -> 선택 목록에서 대상 제거
  -> ReadyToConfirm이면 PickMultipleTargets로 전환
  -> RefreshTargetVisuals
  -> 대상 테두리 푸른색에서 황금색으로 변경
  -> 확인 버튼 숨김
```

## 6. 오류 및 경계 조건

- 단일 대상은 선택 목록에 있더라도 토글하지 않고 기존 완료 흐름을 유지한다.
- 확인 준비 상태에서 선택되지 않은 추가 대상 클릭은 상태를 바꾸지 않는다.
- 대상 종류가 다르면 상태를 바꾸지 않는다.
- 선택 해제는 카드, 운명력, 실행 순서 또는 세션 상태를 변경하지 않는다.
- 선택 해제 직후 빈 영역 취소를 입력하면 기존 전체 정리 흐름을 사용한다.
- 다중 대상이 둘보다 많아도 같은 규칙을 적용하며, 한 번 클릭할 때 정확히 한 대상만 제거한다.

## 7. 검증

### 7.1 헤드리스 테스트

- `PickMultipleTargets`에서 선택된 대상을 재클릭하면 목록에서 제거된다.
- 필요한 대상 수를 채운 `ReadyToConfirm`에서 재클릭하면 `PickMultipleTargets`로 돌아간다.
- 해제한 대상을 다시 클릭하면 목록에 다시 추가되고 요구 수 충족 시 `ReadyToConfirm`으로 돌아간다.
- `ReadyToConfirm`에서 선택되지 않은 추가 대상 클릭은 무시된다.
- 단일 대상 첫 클릭 즉시 완료 동작은 유지된다.

### 7.2 Unity EditMode 테스트

- 다중 대상 두 개를 고르면 둘 다 푸른색이고 확인 버튼이 표시된다.
- 그중 하나를 다시 클릭하면 해당 대상은 황금색으로 돌아가고 나머지는 푸른색을 유지한다.
- 선택 해제 직후 확인 버튼은 숨겨진다.
- 다시 요구 수를 채우면 확인 버튼이 표시된다.
- 아군·적·실행 순서 대상은 같은 코어 토글 결과를 기존 공통 표현 경로로 반영한다.

### 7.3 수동 플레이 검증

- 자리 교환처럼 대상 둘을 고르는 카드에서 첫 대상을 재클릭해 선택을 취소할 수 있다.
- 두 대상을 모두 고른 뒤 하나를 재클릭하면 확인 버튼이 사라진다.
- 해제된 대상을 다시 고르면 푸른색 테두리와 확인 버튼이 복구된다.
- 선택 해제와 재선택 과정에서 카드나 운명력이 소비되지 않고 Console 오류가 없다.
