효과마다 반응하고,
카드가 끝나면 승패를 판정한다

실행 카드의 위치 선택·조건·소비 보상을 명확히 분리하고, 사건에 반응하는 능력과 상태 만료를 공통 계약으로 만든다. 다중 적 정책 작업, 런·유산·세이브, 표현 연출은 이번 범위에서 제외한다.

무엇을 만드나

카드 내부 효과는 순서대로 진행한다. 각 효과는 현재 위치에서 대상을 선택하고, 그 효과가 유발한 반응을 즉시 해결한다. 카드가 시작된 뒤 수행자가 죽어도 남은 효과를 처리하며, 카드와 직접 반응이 모두 끝난 시점에 패배 우선으로 승패를 판정한다.

광역 효과는 전체 대상에 적용한 뒤 반응한다. 반응이 만든 변화는 정상 반영하지만 추가 반응을 발동시키지 않는다. 카드 시작 성공 조건은 고정하고, 소비에 대한 보상은 실제 소비 결과를 참조한다.

새 이름은 제안이다. 기존 효과 처리기와 레지스트리를 재사용한다. 조정자는 호출 순서만 결정하고, 피해·조건·만료 규칙을 직접 소유하지 않는다.

의존 방향

카드 실행기에 호출이 모이는 이유는 효과 간 진행을 제어하기 위해서다. 효과 계산은 처리기에 위임한다. 반응 효과도 동일한 효과 경계를 사용하되, 반응 기원 표시로 재발동을 차단한다. 공통 사망 정리는 능력이 아니라 필수 상태 정리다.

확장 축

등록·데이터로 확장이번 계약에서 고정
효과 종류, 조건 판정, 위치 선택, 사건 종류, 능력별 발동 요건, 상태 만료 정책효과 순차 수행, 효과 직후 반응, 반응의 추가 반응 금지, 카드 종료 승패 판정
Exact / UpTo 소비와 특정 효과 결과를 읽는 보상카드 시작 조건 결과 고정, 효과마다 위치 재선택
사망 시 능력과 생존이 필요한 반격의 개별 요건방어로 전부 막아도 공격받음 사건 발생, 피해 계산·사망 정리는 항상 수행

위치 규칙은 아군·적군 축에 각각 두고 효과가 축을 참조한다. JSON 오류는 로딩에서 거부한다. 실행 결과는 콘텐츠에 저장하지 않는다. 신규 스키마 버전과 구형 변환은 로딩 경계에 두는 안을 제안한다.

방어도 전용 시점은 만들지 않는다. 모든 상태가 공유하는 ‘턴 준비 만료’를 방어에 적용하고, 턴 시작 능력은 그 뒤에 발동한다. 재부여는 기존 부여 순서를 유지한다.

대안과 기각 이유

채택: 효과 직후 반응

모든 효과에 동일한 경계를 적용한다. 연속 피해도 타격마다 반응한다.

기각: 카드 종료까지 보류

연속 공격 중 매번 반격하는 의도를 충족하지 않는다. 카드별 임의 묶음도 숨은 규칙이므로 채택하지 않는다.

채택: 효과마다 위치 선택

앞 효과 → 위치 변화 → 다음 효과가 새 위치를 해석

기각: 카드 전체 대상 고정

카드 시작의 개체를 계속 기억 → 위치를 지정한다는 의도와 불일치

이 선택으로 어려워지는 것

  • 효과 순서가 규칙 의미가 되므로 JSON 재정렬이나 편집 도구 이동이 결과를 바꾼다. 왕복 검증이 필요하다.
  • 기존 카드별 대상 고정 테스트와 취소 처리 테스트는 새 계약으로 바꿔야 한다. 과거 테스트 통과만으로 새 규칙을 보증할 수 없다.
  • 반응에서 발생한 사망 능력도 연쇄 금지 대상이다. 필수 사망 정리와 능력 발동을 혼동하면 카드 제거까지 누락된다.
  • 수행자가 죽어도 시작한 카드가 계속되고, 마지막 적이 죽어도 남은 아군 효과가 진행된다. 카드 종료 경계까지 승패를 미뤄야 한다.
  • 일반 카드 성공 조건과 소비 결과 의존을 따로 표현해야 한다. 서로 다른 기존 조건을 자동으로 한 조건에 합치면 카드 의미가 변한다.

실행 예시

가상 카드: 적군 가장 앞, 피해 3 → 자신 방어 3 → 피해 3. 아군 P의 HP 10, 적 A의 HP 8. A는 공격받을 때 피해 2로 반격한다.

담당·입력결과
CardExecutor: 카드 시작 조건 확정이번 카드의 조건 결과 유지
EffectExecutor: 첫 피해 3, FrontOne=AA HP 5, 공격받음 사건
ReactionDispatcher: A 반격 2P HP 8. 추가 반응 없음
EffectExecutor: 자신 방어 3P 방어 3
EffectExecutor: 두 번째 피해 3, 현재 FrontOne=AA HP 2
ReactionDispatcher: A 반격 2P HP 8, 방어 1
카드 종료 승패 판정전투 계속

첫 피해가 마지막 적을 처치한 경우에도 자신 방어 효과는 수행하고, 다음 피해는 대상이 없어 미적용된 뒤 카드 종료 시 승리한다. 카드 안에서 양측이 전멸하면 패배다.

검토가 필요한 구체화와 실행 순서

추가 제안: 교환으로 동률 카드 순서가 뒤집힌 뒤 새 카드를 넣을 때 기존 카드들은 재정렬하지 않는다. 새 플레이어 카드는 해당 번호의 마지막 플레이어 뒤(없으면 구간 맨 앞), 새 적 카드는 구간 맨 뒤에 삽입한다. 신규 JSON에는 버전을 명시한다. 이 세칙은 대화 합의를 구현 가능한 형태로 구체화한 제안이다.

현재 반응 수용 사례는 사건 당사자의 능력이다. 사건 대상 외의 전역 관찰자까지 지원할 때는 관찰자 순서를 추가로 명시해야 한다. 사건 등록 구조는 확장 가능하게 두며 모든 반응 종류가 이미 구현됐다고 간주하지 않는다.
