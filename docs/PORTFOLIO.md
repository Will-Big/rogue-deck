# Fate Weaver — 기술 소개 (공개용)

> 이 문서는 비공개 상용 프로젝트의 공개용 기술 소개 초안이다. 블로그/노션/이력서 첨부로 옮겨 쓰는 것을 전제로 하며, 저장소 본문은 공개하지 않는다. 게시 전에 `[스크린샷]` 자리에 실제 캡처를 넣을 것 (`docs/media/`에 보관).

**Fate Weaver**는 Unity 6 기반 턴제 덱빌딩 로그라이크 전투 게임입니다 (개인 개발, 상용화 목표).

`[스크린샷/GIF: 전투 화면 — 미래 영역에 카드가 배치되고 개입 카드로 순서를 바꾸는 장면]`

카드를 즉시 사용하는 대신 **미래 영역에 실행을 예약**하고, 실행 **순서 자체를 자원으로 조작**합니다. "첫 번째로 발동하면 강화"류의 조건부 보상이 순서 조작과 맞물려, 같은 손패로도 배치에 따라 완전히 다른 턴이 나옵니다.

## 기술 하이라이트

### 1. UnityEngine 무참조 결정론 코어

게임 규칙 전체가 순수 C# 어셈블리(`FateWeaver.Core`)에 있고, asmdef `noEngineReferences`로 UnityEngine 참조가 컴파일 수준에서 차단됩니다. 모든 무작위는 전투 상태가 소유한 시드 RNG 하나를 경유하므로 **같은 시나리오+시드 = 같은 이벤트 타임라인**이 보장되고, 이 불변식 자체가 회귀 테스트로 고정되어 있습니다. 코어의 유일한 출력은 이벤트 타임라인이며, Unity 레이어는 그 이벤트를 재생하는 표현층입니다.

### 2. Unity 없이 도는 테스트 300+개

헤드리스 `dotnet test` 하니스가 Unity가 컴파일하는 것과 동일한 소스를 LangVersion 9로 컴파일해, **Unity의 컴파일 제약까지 프록시**하면서 에디터 없이 1초 안에 전체 규칙을 검증합니다. 카드 콘텐츠는 golden 서명 테스트로 고정해 리팩토링 중 수치·조건이 변질되면 즉시 실패합니다 — 실제로 이 테스트가 손코딩 덱과 저작 데이터 사이의 3건의 콘텐츠 드리프트를 잡아냈습니다.

### 3. "새 효과 = 파일 1개"인 열린 확장 구조

효과·상태이상·개입 액션은 타입 안전 키 + 핸들러 레지스트리로 확장합니다. 저작 층도 같은 원칙으로 열어서(`[SerializeReference]` 다형 spec 클래스), 새 효과 하나가 **실행 로직·인스펙터 저작·설명 자동 생성·검증·코드 생성 리터럴을 전부 자기 클래스에 담습니다**. 이를 증명하기 위해 샘플 효과(치유)를 테스트 파일 하나만으로 추가하는 테스트를 유지합니다 — 해당 커밋의 diff에 중앙 파일이 등장하지 않는 것 자체가 회귀 방지 장치입니다.

### 4. ScriptableObject 저작 → 코드 생성 파이프라인

디자이너 관점의 카드 저작은 Unity 인스펙터(SO)에서 하고, 에디터 메뉴가 순수 C# spec 리터럴을 생성해 **헤드리스 시뮬레이션과 Unity가 동일한 스키마를 소비**합니다. 저작 실수(미등록 상태 키, 잘못된 파라미터)는 에디터 검증·코드 생성 게이트·부팅 검증 세 지점에서 잡힙니다.

### 5. 문서가 남는 AI 협업 개발 프로세스

모든 기능·리팩토링이 **브레인스토밍 → 설계 스펙 → 구현 계획 → 태스크별 구현+2단계 리뷰** 파이프라인으로 진행되며, 산출물(설계 스펙 20+, 구현 계획 31+)이 저장소에 커밋됩니다. 여러 AI 세션이 병렬로 작업하기 때문에 git worktree 격리·머지 승인 규칙을 저장소 규약(AGENTS.md)으로 명문화했고, 태스크별 구현은 서브에이전트에 위임하고 리뷰 게이트로 품질을 잡는 방식을 씁니다. "AI가 짠 코드"가 아니라 **AI를 팀으로 운용하는 엔지니어링 프로세스**를 보여주는 부분입니다.

## 기술 스택

| 영역 | 선택 |
|---|---|
| 엔진/표현 | Unity 6 (UGUI), ScriptableObject 저작 |
| 규칙 코어 | 순수 C# 9, 이벤트 소싱 스타일 타임라인, 시드 RNG 결정론 |
| 테스트 | NUnit, 헤드리스 dotnet test 300+, golden 콘텐츠 서명, Compare 밸런스 하니스 |
| 프로세스 | 스펙/계획 문서 주도, 멀티 세션 AI 협업 (worktree 격리, 태스크별 리뷰) |
